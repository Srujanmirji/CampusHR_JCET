# CampusHR Design System

## Mobile V2 authority

For future Faculty/HOD mobile design, use [CampusHR Mobile Design System V2](mobile-v2/DESIGN_SYSTEM.md), its [tokens](mobile-v2/tokens.json) and [component specimens](mobile-v2/COMPONENT_SPECIMENS.pdf). The guidance below is the earlier shared/web reference; V2 supersedes its mobile visual values. The running app has not yet adopted V2.

## Visual Direction

Professional academic enterprise UI.

## Brand Colors

- Primary Navy: `#051F5B`
- Accent Orange: `#F05023`
- Warm Red: `#D32F2F`
- Light Gray: `#F5F7FA`
- Text Dark: `#1F2937`
- Success: `#10B981`
- Warning: `#F59E0B`
- Error: `#EF4444`
- White: `#FFFFFF`

## Typography

Recommended:

- Inter
- Manrope
- Geist

Use one family consistently.

## Radius

- Inputs: 10px
- Buttons: 10px
- Cards: 14px
- Modals: 16px

## Shadows

Subtle only. Avoid heavy glassmorphism.

## Components

- Sidebar
- Topbar
- Metric Card
- Data Table
- Badge
- Tabs
- Filter Bar
- Search
- Drawer
- Modal
- Select
- Date Picker
- Empty State
- Skeleton
- Toast
- Confirmation Dialog

## UX Rules

- Primary actions must be obvious.
- Destructive actions require confirmation.
- Tables should support search/filter/sort.
- Mobile views should prioritize daily actions.
- Approval flows should show current status and next approver.
