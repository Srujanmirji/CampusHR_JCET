# Mobile UX Specification

> **Canonical mobile visual authority:** [CampusHR Mobile Design System V2](mobile-v2/DESIGN_SYSTEM.md). Use V2 for all later Faculty/HOD screens, role-specific navigation and component states. This earlier UX outline is historical context; it does not override V2. Runtime migration is separate.

## Bottom Navigation

- Home
- Timetable
- Attendance
- Leave
- Profile

## Home

- Greeting
- Today’s classes
- Attendance percentage
- Leave balance
- Latest notifications
- Quick actions

## Mobile Priorities

1. View timetable
2. Mark/view attendance
3. Apply leave
4. View leave status
5. Receive substitute assignment
6. View notices
7. Upload documents

## Interaction Principles

- One-handed usage
- Large tap targets
- Low form complexity
- Minimal typing
- Clear status chips
