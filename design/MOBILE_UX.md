# Mobile UX Specification

## Bottom Navigation

- Home
- Timetable
- Attendance
- Leave
- Profile

## Home

- Greeting
- Today’s classes
- Attendance percentage
- Leave balance
- Latest notifications
- Quick actions

## Mobile Priorities

1. View timetable
2. Mark/view attendance
3. Apply leave
4. View leave status
5. Receive substitute assignment
6. View payslip
7. View notices
8. Upload documents

## Interaction Principles

- One-handed usage
- Large tap targets
- Low form complexity
- Minimal typing
- Clear status chips
