- Left sidebar
- Top navigation
- Main content area
- Optional right contextual panel

Cards:

- Total Employees

- Absent Today
- On Leave
- Pending Approvals
- Departments

- Employees by Department
- Attendance Trend

- Workload Distribution

Tables:

- Recent Leave Requests

- Missing Documents

## Responsive

- Desktop-first for admin.
- Tablet fully supported.
- Mobile web usable but not primary admin interface.
