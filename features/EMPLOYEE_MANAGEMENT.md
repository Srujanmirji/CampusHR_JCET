# Feature — Employee Management

## Capabilities

- Create employee
- Update employee
- View employee profile
- Archive/deactivate employee
- Assign department
- Assign designation
- Store qualifications
- Store experience
- Store statutory details (Aadhaar, PAN)
- Employee ID generation
- Search and filters

## Employee Profile Sections

- Personal
- Employment
- Academic
- Documents
- Attendance
- Leave
- Workload
- Research
