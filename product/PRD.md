# Product Requirements Document — CampusHR

## 1. Product Name

**CampusHR — Human Resource & Faculty Management System for JCET Hubballi**

## 2. Problem

College HR operations are often spread across spreadsheets, attendance systems, paper leave forms, payroll files, timetable documents, messaging apps, and departmental records.

CampusHR centralizes these workflows into one system.

## 3. Primary Users

### Admin / HR
- Manage employees
- Manage departments
- Process attendance
- Manage leave
- Process payroll
- Manage documents
- Generate reports
- Configure system

### HOD
- Manage department faculty
- Approve leave
- Review workload
- Assign timetable
- Approve substitutions
- View department reports

### Principal
- View institution-wide analytics
- Review staffing
- Review department performance
- Access HR and academic reports
- Approve high-level workflows

### Faculty / Staff
- View profile
- View attendance
- Apply for leave
- View timetable
- View workload
- Receive substitution assignments
- View payslips
- Upload documents
- Receive notices

## 4. Product Platforms

### Web
Primary platform for HR, Admin, HOD, Principal.

### Mobile
Primary platform for Faculty and Staff.

## 6. MVP

MVP must include:

- Login
- Role-based access
- Employee records
- Department records
- Attendance
- Leave request + approval
- Timetable
- Faculty workload
- Smart substitution
- Notifications
- Reports dashboard
- Mobile faculty view

## 7. Success Criteria

- HR can manage staff from one dashboard.
- Faculty can complete daily HR actions from mobile.
- HOD can approve leave and assign substitutes.
- Timetable conflicts are detected.
- Workload is measurable.
- All important actions are audit logged.
- Reports are exportable.

## 8. Non-Functional Requirements

- Responsive
- Secure
- Role-based
- Accessible
- Fast initial load
- API validation
- Auditability
- Backup-ready
- Scalable for multiple departments
